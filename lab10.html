Lab 10 Notes

Summary: In this lab, we were tasked with creating a .htaccess file to control access to certain files in our lab directory and a .htpasswd file to store user credentials for HTTP authentication. The .htaccess file was configured to restrict access to the lab directory and require authentication for certain files. The .htpasswd file was created using the htpasswd command to generate encrypted passwords for the users. This lab provided hands-on experience with configuring web server access control and understanding the use of .htaccess and .htpasswd files in securing web directories.

Lessons learned: Configuring web server access control and understanding the use of .htaccess and .htpasswd files in securing web directories.
